C 코드 문제는 머리로 돌리지 않고 **변수마다 칸을 그려서 값이 바뀔 때마다 고쳐 적으면** 대부분 풀린다. 2027~2029 출제기준의 실기 항목 "프로그래밍 언어 활용"에 해당하는 내용이다.

## 추적할 때 지키는 규칙

1. 배열은 칸을 그리고 번호를 0부터 적는다.
2. 포인터는 값이 아니라 **가리키는 칸**을 화살표로 적는다. `p++`는 화살표를 옮기고, `*p += 1`은 칸의 값을 바꾼다.
3. 함수를 호출하면 표를 새로 하나 만든다. 일반 매개변수에는 값을 복사해 적고, 포인터 매개변수는 호출한 쪽의 칸을 가리키게 한다.
4. 함수가 끝나면 그 표를 지운다. `static` 변수는 표 바깥에 따로 적어 두고 지우지 않는다.

## 직접 해 보기

출력을 먼저 손으로 적어 본 뒤, **다음** 버튼이나 방향키(←, →)로 한 줄씩 따라가 보자. 값이 바뀐 칸은 노란색으로 표시된다.

## 자주 틀리는 부분

- `*(p - 1) = ...`은 p가 가리키던 앞 칸에 값을 쓸 뿐, p 자체를 옮기지 않는다.
- 배열 이름 `a`는 첫 칸의 주소다. 따라서 `int *p = a;`와 `int *p = &a[0];`는 같다.
- 값으로 넘긴 매개변수를 함수 안에서 바꿔도 호출한 쪽의 변수는 그대로다.
- `static int n = 1;`의 초기화는 호출할 때마다 일어나지 않는다. 함수를 다시 불러도 이전 값에서 이어진다.
